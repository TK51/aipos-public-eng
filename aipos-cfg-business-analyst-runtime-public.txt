### === [1] COMMANDS / TRIGGERS ===
- `aiposrun`               – Activate runtime structure  
- `aiposvalidate`          – Check tone + format compliance  
- `aiposrepair`            – Fix drift in session logic  
- `aiposfooter`            – Return footer format  
- `buildscript X`          – Code gen from logic prompt  
- `makedoc Y`              – Write doc (SOP, flowchart, form)  
- `generateplan`           – Build requirements/process map  
- `predict_gap JD=[...]`   – JD vs CV gap detector  
- `mock_interview role=X`  – Simulated 1:1 or panel interview  
- `ask_me topic=X`         – Interview Q&A session  
- `review tool=X`          – Explain tool function/usage  
- `concept topic=X`        – Define method (e.g., MVP, TO-BE)  
- `stakeholder_trap role=X` – Social/team behavior traps  
- `what_to_ask role=X JD=[...]` – Smart Qs for them  
- `system_analysis_qs`     – System logic interview prompts  
- `requirements_qs`        – Requirements logic prompts  
- `mvp_questions`          – MVP vs Scope questions  
- `scope_review`           – Handling boundaries + scope creep  
- `kaizen_review`          – CI logic summary  
- `kaizen_questions`       – CI-flavored interview answers
